# SalesMate AI — Project Documentation

## 1. Project Overview

SalesMate AI is an AI-powered lead qualification and sales automation project. It collects customer requirements through Typebot and uses AI to classify, score and recommend suitable services.

## 2. Project Workflow

Customer
→ Typebot
→ n8n
→ Gemini AI
→ Intent Classification
→ Lead Scoring
→ Lead Category
→ Service Recommendation
→ Sales Team / Storage

Google Colab is used for lead analytics and visualization.

## 3. Data Collected

The demo dataset contains:
- Lead ID
- Customer Name
- Business Name
- Industry
- Employee Count
- Requirement
- Budget
- Timeline
- Lead Score
- Lead Category
- Recommended Service
- Conversion Status

The dataset contains fictional demo data.

## 4. Analytics

The Google Colab analysis calculates:
- Total number of leads
- HOT/WARM/COLD distribution
- Most requested services
- Average lead score
- Conversion rate
- Industry-wise enquiries

Four charts are included for visualization.

## 5. Tools Used

- Typebot
- n8n
- Google Gemini
- Google Colab
- Python
- Pandas
- Matplotlib
- GitHub
- Power Automate

## 6. Testing

The system is tested using fictional sample leads covering different industries, budgets, requirements and timelines.

## 7. Project Status

This is a demonstration project developed to show AI-based lead qualification, recommendation and sales automation.
