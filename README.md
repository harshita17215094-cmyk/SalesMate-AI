# SalesMate AI

AI-powered lead qualification and sales automation project.

## What It Does

SalesMate AI collects customer requirements, analyzes leads using AI, assigns lead scores and categories, and recommends suitable services.

## Workflow

Customer → Typebot → n8n → Gemini AI → Lead Scoring → Recommendation → Sales Team

Google Colab is used for analytics and visualizations.

## Technologies

- Typebot
- n8n
- Google Gemini
- Google Colab
- Python
- Pandas
- Matplotlib
- Power Automate
- GitHub
